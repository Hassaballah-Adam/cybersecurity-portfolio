## 🗂️ What I've Learned

### 🖥️ Linux & System Administration
- Setting up and managing Virtual Machines
- Core terminal commands: `mkdir`, `cd`, `cat`, `nano`, `chmod`
- File permissions, directory structure, and SUID auditing
- Security automation with bash and log parsing with `sed`, `awk`, and `grep`

### 🌐 Networking & Protocol Analysis
- OSI model and TCP/IP fundamentals
- TLS handshake analysis with Wireshark
- IP subnetting, CIDR notation, and network segmentation
- DNS interrogation and protocol auditing

### 🐍 Python for Security
- Service enumeration and TCP connect scanning
- System interrogation and automated audit logging
- Network scripting and banner grabbing

### 🐳 Docker & Containers
- Virtualization concepts and multi-container architecture
- Secure Dockerfile design — non-root users, minimal images
- Docker Compose deployment with air-gapped backend networking

### 🏢 Identity & Active Directory
- IAM provisioning and MFA enforcement with PowerShell
- Group Policy design and access control auditing
- Linux-Windows domain join and unified identity management

### 🔍 Reconnaissance & Exploitation
- Passive OSINT and threat profiling
- Active scanning with Nmap and Nikto
- Exploitation with Metasploit, Burp Suite, SQLmap, and XSS payloads

### 🔬 Digital Forensics & Incident Response
- Chain of custody and live triage
- Disk and memory forensics
- Incident response documentation using the PICERL framework

### 🛡️ Active Defense
- Firewall rule design and UFW configuration
- Custom Suricata IDS rules and alert tuning
- EDR policy configuration and endpoint telemetry analysis
