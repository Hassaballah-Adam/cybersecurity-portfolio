QUESTIONS:
1. What Nmap flag did you use to find the specific software versions running on these ports?
Answer: The -sV flag was used to perform version detection. It probes open ports to determine the exact service name and version number running on each port.

2. Why is it dangerous to run an intense scan like -A on a fragile legacy system?
Answer: The -A flag enables aggressive scanning including OS detection, version detection, script scanning, and traceroute. On fragile legacy systems this can cause crashes because the flood of probes overwhelms old hardware or unpatched software not designed to handle such traffic.
